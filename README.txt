EASY ROSTER - IPHONE WEB APP

What it includes
- Home screen with AM, PM, Night and Weekly Roster buttons
- Monday to Sunday roster
- Staff name and ward/unit
- Start and finish times
- Sick Call
- Sick Leave: Full shift, Part shift, Personal leave
- Replacement staff
- Notes
- Search and filtering
- Local device saving
- Backup import/export
- Print / Save PDF
- Offline support when installed from a web server

IMPORTANT FOR IPHONE INSTALLATION
A true Add to Home Screen web app works best when these files are hosted on a website using HTTPS.
Opening index.html directly from the Files app will let you use the roster, but iPhone may not install it as a full standalone app.

To install once hosted:
1. Open the app website in Safari.
2. Tap Share.
3. Tap Add to Home Screen.
4. Tap Add.
5. Open Easy Roster from your iPhone Home Screen.

Your roster data stays in that browser/app on your device. Use Export Backup regularly.
